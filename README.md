# Sunshine Surgicals Website

A responsive, animated static website for Sunshine Surgicals, Ahmedabad.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive design, animations and color system
- `script.js` — mobile menu, scroll animations, counter, quote form and UI interactions
- `assets/shop-front.jpg` — temporary storefront image supplied for the first version

## Brand palette
- Sunshine Orange: #F47B20
- Warm Yellow: #FFC928
- Deep Orange: #D95D0B
- Soft Cream: #FFF9E8
- Charcoal: #242424
- White: #FFFFFF

## Before publishing
1. Replace the temporary text/sun mark with the final Sunshine Surgicals logo.
2. Add real product photos/catalogue images when available.
3. Review product categories and brand names for accuracy.
4. Add any required legal pages, registrations/certifications and business policies.
5. Connect the quote form to a backend/CRM if you want enquiries stored instead of opening WhatsApp.

## Run locally
Open `index.html` directly in a modern browser, or use a local static server.
